# Third-party assets

## Loop Town

- File: `public/audio/loopcity.ogg`
- Author: Fupi
- Source: <https://opengameart.org/content/loop-town>
- License: Creative Commons Zero (CC0 1.0)
- Use: Optional in-game background music, disabled until the player presses the
  visible music control so browser autoplay policies are respected.

The checked-in Realmseed sprite atlas is original project artwork generated by
the deterministic `scripts/build_pixel_atlas.py` source. The game code and
pixel graphics do not copy data, replays, or graphics from
`FromUnknown2Lover`. That project informed only the static-first deployment
boundary and the preference for an expressive pixel map.
